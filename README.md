# E-Commerce

Full-stack e-commerce project built with **Next.js**, **Node.js**, **Express**, and **TypeScript**.

## Technologies

### Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS

### Backend

* Node.js
* Express
* TypeScript
* REST API

## Run Locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs on:

```
http://localhost:3000
```

### Backend

```bash
cd backend
npm install
npm run dev
```

Runs on:

```
http://localhost:3001
```
